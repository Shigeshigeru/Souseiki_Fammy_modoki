創世紀ファミーモドキ  

かつて存在した創世紀ファミーの機能にカセットのゲームを  
ディスクシステムに変換する操作がついていました  

その機能のみを再現する試みです  

現状でも関連資料は残されているので自力変換は可能なのですが  
めんどくさいのでAIに手伝ってもらいながら  
自分もお勉強して変換プログラムが完成されるのが目標です  

「いっき」は動作しました

**A面バトルシティー、B面バルーンファイトの
テンプレートも用意しておきます！！**

大事なこと  
実ディスク、実機でも確認予定ですが  
実ディスク使用するとディスクIDが  
書き換えられでっち上げIDとなるはずです  
大事なディスクはバックアップしておいてください
